# Code Review

As part of CS 499: Computer Science Capstone, I completed a code review of the three artifacts selected for enhancement in my ePortfolio. The review examines the existing code, identifies areas that could be improved, and explains the enhancements planned for the software design and engineering, algorithms and data structures, and database categories.

The artifacts reviewed were:

- Travlr Getaways
- Treasure Hunt
- Grazioso Salvare Dashboard

The code review provided the starting point for evaluating each artifact before making changes. It allowed me to examine the existing design, identify weaknesses or opportunities for improvement, and explain how the planned enhancements would demonstrate the CS 499 course outcomes.
